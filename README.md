# Thicken

> **Versión actual: 1.0.0** (Blender 4.2 – 5.x) → instalar `version_1.0.0/dist/thicken-1.0.0.zip`

Complemento de Blender que **engorda solo las zonas demasiado finas** para imprimir (pestañas, bordes, dedos, barras) hasta el grosor mínimo de tu boquilla.

Marca las zonas finas, las hace crecer por sus dos caras hasta el mínimo con una transición suave y repasa lo que falte. El resto del modelo queda igual. Copia nueva, original oculto, colores conservados.

## Familia de plugins

**Mesh Doctor → Print Scale → Thicken → Base Support → BigPrint / MagSnap → Color Print Splitter**
